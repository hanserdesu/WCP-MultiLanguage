## 交付总览与架构对齐

本项目完全符合 `D:\ATooManyLanguage\Japanese\ARCHITECTURE-UNIFIED.md` 规定的解耦多语言接入标准，支持单册独立导入与多语言并存：

| 模块 / 资源 | 物理路径 | 规格与契约说明 |
|---|---|---|
| **Excel 词书** | `output/import/粤语词库(猫条版).xlsx`<br>`packs/yue/books/粤语词库(猫条版).xlsx` | **严格无表头**（NPOI 契约从第 0 行直接读取），A列=词，B列=释义（格式：`[粤拼] 中文释义〈词性〉`），C/D列放粤拼与级别供参考，共 384 词。 |
| **释义数据库** | `packs/yue/db/meaning.sqlite` | 独立 SQLite 数据库，内含标准的 `pron(word, ukPhonic, usPhonic, meaning)` 表，共 384 行。 |
| **例句主库** | `output/sentences_master.json`<br>`packs/yue/db/sentences.json` | 遵循统一 `schema: 1` 规范，384 词全部 100% 覆盖真实地道粤语例句，包含粤语字形、粤拼注音及普通话翻译。 |
| **离线自愈载荷** | `packs/yue/db/repair.tsv`<br>`output/yue_db_payload/` | 遵循 `#\tschema=1` 规范的 TSV 流（共 1,153 行）与带 SHA-256 校验的自愈清单，防止官方更新冲掉词库。 |
| **Pack 清单** | `packs/yue/manifest.json` | 统一架构元数据清单：词数 384 词，并集 SHA-256 指纹为 `0748ca590e7caf6c2d11e5062ee381e2a3e1ac84f943c561a4fed94568f0cb9e`，内置探针词 `["食", "睇", "搞掂"]`。 |
| **Pack 策略** | `packs/yue/WcpPack.Yue.dll` | 统一架构 L2 策略程序集，实现 `ILanguageStrategy` 与 `IPackBoundStrategy`。 |
| **运行时 Mod** | `mod_book_name/BookNameMod.dll`<br>`mod_yue_wordlist/YueWordListMod.dll`<br>`mod_sentence_audio_yue/SentenceAudioYueMod.dll` | 适配 BepInEx 5，五语跨语言指纹匹配 (`BookProfiles.cs`)、`YUE` 语音标签、`YueWL_*` 词表作用域门与例句播放。 |
| **TTS 音频管线** | `tools/gen_word_audio.py`<br>`tools/gen_sentence_audio_yue.py` | 基于 edge-tts `zh-HK-HiuGaaiNeural` 粤语母语音色，单词私有化命名、例句按 MD5 规范命名。 |

## 词库全领域分级体系 (18 大分类，384 核心词)

词库涵盖广府白话与港式粤语日常学习的全部核心场景：

1. **L1 基础日常核心 (120 词)**：代词、指示词、疑问词、超高频动词（食、睇、搵、畀、整、搞掂、返工、放工、瞓覺等）、核心形容词与助词。
2. **L2 生活社交与饮食出行 (61 词)**：饮茶早点（蝦餃、燒賣、叉燒包、腸粉、鳳爪、蛋撻）、交通买卖（地鐵、巴士、的士、八達通、增值、找錢、銀包、散紙、蚊）及起居家务。
3. **L3 地道俚语与熟语俗语 (33 词)**：經典口頭禪（執生、炒魷魚、食死貓、吹水、放飛機、扮嘢、蛇王、心水、濕碎、縮沙、死頂、撐枱腳、鬼馬、閉翳、頂唔順、巴閉、孤寒、搏命、一頭霧水、七國咁亂、托塔都掂等）。
4. **L4 职场商贸与现代交际 (20 词)**：寫字樓、人工、出差、開會、見工、跳槽、升職、講價、過數、簽單、合約、講數、搞生意、大客、執笠等。
5. **L5 人体情感与日常扩展 (20 词)**：頭痛、心痛、手足、眼瞓、醒目、蠢、心慌、放心、傷心、激氣、發脾氣、落雨、打風、濕熱、涼茶、熱氣等。
6. **L6 特征量词与语法虚词助词 (20 词)**：粤语核心独特量词（嚿、粒、樖、啖、樽、隻、餐、陣、篤）及核心时态助词语气助词（緊、咗、過、埋、晒、親、定、返、啫、喎、添）。
7. **L7 港式茶餐厅与粤菜美食全集 (15 词)**：茶走、鴛鴦、菠蘿油、乾炒牛河、滑蛋牛肉、西多士、車仔麵、魚蛋、雞蛋仔、碗仔翅、煎釀三寶、雙皮奶、楊枝甘露、燒鵝、牛腩。
8. **L8 地道性格气质与心理情绪 (10 词)**：牙擦、心悒、生性、百厭、扭計、發老脾、大懵、論盡、肉緊、唔忿氣。
9. **L9 经典广府熟语与民间歇后语 (7 词)**：水過鴨背、扮豬食老虎、死雞撐飯蓋、扯貓尾、過橋抽板、一擔擔、牛頭唔對馬嘴。
10. **L10 现代职场商贸与都市金融生活 (10 词)**：出糧、花紅、雙糧、遞信、炒散、開OT、走數、孭鑊、卸膊、手頭緊。
11. **L11 亲属称谓与人际社交 (12 词)**：老竇、老母、阿爸、阿媽、阿哥、阿嫂、細佬、細妹、阿爺、阿嫲、阿公、婆婆。
12. **L12 家居设施与日常用品 (10 词)**：梳化、茶几、衣櫃、風筒、花灑、電掣、拖板、膠袋、紙巾、番梘。
13. **L13 身体部位与就医健康 (10 词)**：頸、肚、背脊、膝頭哥、睇醫生、發燒、感冒、肚痛、食藥、保重。
14. **L14 粤菜烹饪技艺与风味口感 (8 词)**：煲、燉、蒸、灼、焗、鑊氣、爽脆、入味。
15. **L15 城市交通与市政设施 (7 词)**：機場、碼頭、天星小輪、叮叮車、天橋、斑馬線、紅綠燈。
16. **L16 数字时间度量与高频连词 (8 词)**：同埋、但係、因為、所以、如果、其實、總之、頭先。
17. **L17 情感心理与人际态度 (7 词)**：鍾意、憎、驚、急、慳、嘈、靜。
18. **L18 日常社交礼貌与应答应候 (6 词)**：唔該、多謝、唔好意思、唔緊要、拜拜、慢慢行。
