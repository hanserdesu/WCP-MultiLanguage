WCP 法语词库（猫条版）一键安装包

当前版本：v1.0.0

使用方法：
1. 先关闭万词破（背单词游戏）。
2. 双击运行根目录的「01_双击运行我.cmd」，不要直接进 support 文件夹。
3. 安装器会自动搜索 Steam 游戏目录，并联网从 GitHub 下载法语音频
   （单词 8,116 条 + 例句 24,328 条，约 610MB；下载失败可重跑，已下载部分不会重复下载）。
4. 看到「安装成功」后启动游戏，书单里的「自定义词书二（法语词库(猫条版)）」
   即为本词书，已自动选中；共 8,116 词，每词 3 条例句与法语音频。

说明：
- 不影响官方英语词书与日语词书：英法同形词按当前选中的词书自动切换，
  法语单词发音走独立目录，切到英语/日语词书听到的仍是原版发音。
- 安装前自动备份 MyBook.es3、SaveFile.es3 与已有插件到
  %USERPROFILE%\AppData\LocalLow\WCP\wcp\frmod_backups\<时间戳>。
- 安装器自带 BepInEx 5 运行环境，未装过 Mod 的电脑也能直接安装；
  支持 Windows PowerShell 5.1 与 PowerShell 7。
- 游戏更新或 Steam 校验完整性会覆盖共享词库，插件会在进游戏后自动从本地
  补丁包恢复法语词条；如仍有异常，重跑一次本安装包即可。
- 想按级别分开学：support/payload/books 里的 法语A1A2/B1/B2 分级词书与
  wcp_french.db 已一并放入游戏存档目录，可用游戏内 Excel/外接词库通道导入。
- 法语音频由 edge-tts（fr-FR-DeniseNeural）生成，只读不写系统目录。
