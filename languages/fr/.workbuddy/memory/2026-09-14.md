### 环境备忘（本机）
- Bash 工具的 PATH 是坏的：每条命令前必须 `export PATH="/c/Windows/System32:/c/Windows:/usr/bin:/bin:$PATH"`，否则 `ls`/`head`/`dirname` 都找不到。
- 沙箱**禁止**在 Bash 里调用 `cmd.exe`，也禁止任何含 `csc.exe` 字样的命令 → 编译 C# 插件必须走 PowerShell 工具 `& "D:\French\mod_book_name\build.cmd"`（PowerShell 的 stdout 恒为空，只能靠把输出 `Out-File` 到文件再读）。
- Glob 工具在工作区之外不可靠（`C:/Windows/...` 返回 No files found），要用 bash `ls` 确认。
