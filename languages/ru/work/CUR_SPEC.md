# 俄语词表精选作业规范（子代理必读）

你要为 WCP 俄语词书做 **词表精选 + CEFR 分级 + 中文释义**。
输入是按字幕词频排序的俄语词元块（pymorphy3 从字幕语料还原的词典形）；
你输出精选结果 JSON。

## 你的产出

写文件 `D:\Russian\work\cur_out_NN.json`（NN 为块号，如 `cur_05.json`）。格式：

```json
{
  "kept": [
    {"word": "стол", "zh": "桌子", "level": "a1"},
    {"word": "преображаться", "zh": "改观；变样", "level": "b2"}
  ],
  "drop": [
    {"word": "xxxy", "reason": "乱码/非词"},
    {"word": "ватрушка", "reason": "过于冷僻的饮食词"}
  ]
}
```

## 硬性规则（校验脚本逐条检查，违规即 FAIL）

1. **输入的每个词必须恰好出现一次**：要么在 `kept`，要么在 `drop`。
   既不在 kept 也不在 drop、或两边都出现 = FAIL。顺序可以打乱。
2. `level` 必须是 `a1` / `a2` / `b1` / `b2` 之一。
3. `zh` 必须含中文（CJK），禁止西里尔字母串（3 个以上连续西里尔字母会被拒），
   禁止 4 个以上连续拉丁字母；长度 2~40 字。禁止把重音标注或词性写进 zh。
4. `drop.reason` 非空，10 字以内简短理由。
5. JSON 合法 UTF-8。不要输出 JSON 之外的任何内容到该文件。

## 精选规则（drop 什么）

- 专名（人名/地名/民族名/品牌，如 иван、москва、пушкин）
- 过于冷僻（rank > 7000 且书面/古旧/方言/专业词，普通学习者不需要就 drop）
- 粗俗词（мат 层级的脏话 drop；轻微口语词如 блин 可保留）
- 乱码、非词、纯缩略、明显是字幕噪声的变形（如机器人字幕残留）
- 单字母/虚词若确实常用（и, в, не, а...）必须保留 —— 它们是造句核心
- 英语借词若在俄语日常使用普遍（футбол, шок, спорт）则**保留**
- 同根近形词重复（如同时出现 屈折变体 两个词条）保留更基本的那个，
  另一个 drop 并注明「变体重复」
- drop 总数不要超过该块的 40%（校验会拒绝）

## 保留词的中文释义（zh）

- 简洁词典式：主要义项 1~3 个，用「；」分隔：`好；不错的`
- 名词给单数词典形含义（只有复数形的词如 деньги 给惯用含义）；动词给不定式含义
- 运动动词对（идти/ходить, ехать/ездить）各自保留，释义区分定向/不定向
- 不要写例句、不要写重音、不要写词性、不要写 IPA
- 允许用括号补充限定：`космос（宇宙）`→`宇宙；太空`、`反正（口语）`

## CEFR 分级（按实际难度判断，不严格按 rank）

- a1：最基础生存词汇（问候、数字、家庭、日常物、топ 常用动词）
- a2：日常扩展（描述、情绪、常见抽象词）
- b1：流利表达所需（社会、工作、观点类词汇）
- b2：高级（低频抽象词、正式书面语、精细表达）
- 你的块有 rank 提示：rank 靠前的块整体偏 a1/a2，靠后的偏 b1/b2，
  但**逐词按真实教学难度判断**（如 rank 靠后的 спасибо 也是 a1）。
