# 俄语例句生产作业规范（子代理必读）

你要为 WCP 俄语词书生成 **俄语例句 + 中文翻译**。

## 你的产出

写文件 `D:\Russian\work\gen_out_NN_Y.json`（NN=词块号, Y=批号）。格式：JSON 对象，
键=单词，值=例句数组。

```json
{
"переезжать": [
{"ru": "Мы переезжаем в новую квартиру в следующем месяце.", "zh": "我们下个月搬进新公寓。"},
{"ru": "Он часто переезжал из города в город из-за работы.", "zh": "因为工作他常常从一个城市搬到另一个城市。"},
{"ru": "Хорошо, когда не нужно переезжать каждый год.", "zh": "不用每年搬家真好。"}
]
}
```

## 硬性规则（校验脚本逐条检查，违规即 FAIL）

1. **每个词必须恰好 3 条例句**（不是 2 条，不是 4 条）
2. `ru` 必须以 `.` `!` 或 `?` 结尾（句末引号/省略号不行）
3. `ru` 必须是**地道俄语**——严禁出现汉字/假名，严禁出现
   3 个以上连续拉丁字母，严禁出现 下划线/花括号/{}/<> 等 JSON 模板残留
4. `zh` 必须是**中文**，且**绝对不含西里尔字母和拉丁字母**（2 个以上连续西里尔
   或 4 个以上连续拉丁字母会被拒），也不含括号 （）()
5. 同一个词的多条 `ru` **不得重复**
6. **词的某种自然形式必须出现在例句中** —— 见下
7. 每句 4~14 个单词，长度适中
8. JSON 必须是合法 UTF-8；输出文件只含这一个 JSON 对象

## 规则 6 详解（俄语词形变化丰富）

校验按「去 ё/е 区分、去大小写后的原形或词干前缀」匹配。词的前缀子串
（剥掉末尾 1~4 个字母）命中即通过，绝大多数变格变位自动通过：

- 原形出现：`стол` → "На столе лежит книга." ✔（столе 含词干 стол-）
- 名词变格：`книга` → "Я читаю книгу." ✔（книг- 是 книга 的前缀）
- 动词变位：`читать` → "Он читает газету." ✔（чита- 词干）
- 形容词变化：`новый` → "В новом доме есть лифт." ✔（нов- 词干）
- 副词/比较级：`быстро` → "Он бегает быстрее меня." ✔（быстр- 词干）

**异干词形必须写含原形或下列词干的句子，否则会被拒**：
идти/пойти/прийти/найти/уйти 等 идти 系（接受词干 ид-/ойд-/ш-/йд-，
如 "Я иду домой." ✔ "Она шла в магазин." ✔）
человек（接受 люд-）、ребёнок（接受 дет-）、друг（接受 друж-/друз-）、
брать/взять（接受 воз-/бер-）。
最稳妥的写法：**用现在时第一人称或不定式**（与原形共享明显词干）。

## 例句质量要求

- **自然地道**，像俄罗斯人日常说的话，不要翻译腔
- **情境具体**，能体现该词的典型用法和搭配，不要空洞套话
- **三条各不相同**：不同场景 / 不同搭配 / 不同时态体，不要只换主语
- 句首大写，标点规范（句末标点前不加空格）
- 中文翻译要**通顺**，符合中文表达习惯，不要逐字硬译
- 运动动词注意定向/不定向区分（идти/ходить）
