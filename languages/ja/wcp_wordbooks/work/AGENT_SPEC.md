# 例句生产作业规范（子代理必读）

你要为 WCP 日语词书生成 **日语例句 + 中文翻译**。

## 你的产出

写文件 `D:\Japanese\wcp_wordbooks\work\gen_out_NN_Y.json`（或补丁，见下）。
格式：JSON 对象，键=单词，值=例句数组。

```json
{
"円満": [
{"ja": "二人は話し合いを重ねて、ついに円満に離婚した。", "zh": "两人反复商量之后，最终和平圆满地离了婚。"},
{"ja": "彼の家族はいつも円満で、近所でも評判がいい。", "zh": "他家一向家庭和睦，在街坊里口碑也很好。"},
{"ja": "問題を円満に解決するために、双方が歩み寄る必要がある。", "zh": "为了圆满解决问题，双方都需要各让一步。"}
],
"園": [ ... 3 条 ... ]
}
```

## 硬性规则（校验脚本会逐条检查，违规即 FAIL）

1. **每个词必须恰好 3 条例句**（不是 2 条，不是 4 条）
2. `ja` 必须以 `。` 或 `！` 或 `？` 结尾（句末引号要去掉后再判断）
3. `ja` 必须是**日文** —— 严禁出现简体中文（校验用字符白名单，「国」「学」「气」这类简体形会被拒）
4. `zh` 必须是**中文**，且**绝对不含假名**（校验会扫 `[\u3040-\u30ff]`）
5. 同一个词的多条 `ja` **不得重复**
6. **词形必须出现在例句中** —— 这是最容易踩的坑，见下
7. JSON 必须是合法 UTF-8；用 `ensure_ascii=False`

## 规则 6 详解（血泪教训）

校验逻辑：词的**原形**或**去掉末尾假名的词干**必须字面出现在某条 `ja` 里。

- ❌ `化する` 写成「夢と化した」→ FAIL（只有「化し」，没有「化する」）
- ✅ 写成「夢と化するに終わった」→ PASS
- ❌ `果たす` 写成「夢を果たした」→ FAIL
- ✅ 「約束を果たすために」→ PASS
- 动词尽量用**原形**或「〜ために / 〜べきだ / 〜つもりだ / 〜ことができる」等接续
- 名词、形容动词、副词直接嵌入即可
- 敬语前缀词（御主人/お茶/ご飯）允许用去掉「御/お/ご」的词形

## 例句质量要求

- **自然地道**，像日本人日常会说的话，不要翻译腔
- **情境具体**，能体现该词的典型用法，不要空洞套话
- **三条各不相同**：不同场景 / 不同搭配 / 不同语体，不要只换主语
- 长度适中，10~40 字为宜
- 中文翻译要**通顺**，符合中文表达习惯，不要逐字硬译

## 文件类型说明

### 类型 NEW（文件不存在）
你要新建 `gen_out_NN_Y.json`，包含该批 100 个词，每词 3 条 = 300 条。

### 类型 PATCH（文件已存在但不足 3 条）
文件里每个词已有 2 条（少数已有 3 条）。你只需：
1. 读出已有文件，看清每个词现有什么例句
2. 给**不足 3 条**的词补写差额条数，且新写的 `ja` **不能与已有的重复**
3. 输出一个**只含新增条目**的补丁文件
4. 用工具合并：
   ```
   python tools/gen_helper.py merge NN Y <你的补丁文件路径>
   ```

## 词表查看

```
C:/Users/hanserdesu/.workbuddy/binaries/python/versions/3.13.12/python.exe -c "
import json,sys
sys.stdout.reconfigure(encoding='utf-8')
d=json.loads(open('work/gen_words_NN.json',encoding='utf-8').read())
ks=list(d.items())[Y*100:(Y+1)*100]
for k,v in ks: print(k,'|',v['reading'],'|',v['meaning'],'|',v['level'])
"
```

`meaning` 字段含中文释义和词性（〈名〉〈动1〉〈动2〉〈动3〉〈イ形〉〈ナ形〉〈副〉〈接〉〈惯〉等），
是判断用法的最重要依据。词性决定例句怎么写：

- 〈动1〉五段：書く→書かない/書きます/書いて
- 〈动2〉一段：食べる→食べない/食べます/食べて
- 〈动3〉サ変：する→しない/します/して
- 〈イ形〉形容词：高い→高くない/高かった
- 〈ナ形〉形容动词：静か→静かな/静かに
- 〈名〉名词：直接嵌入
- 〈副〉副词、〈接〉接续词：注意语法位置
