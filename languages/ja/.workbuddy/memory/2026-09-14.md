→ **三语已经在共存，占 3 槽，剩 1 槽。** 用户的"多语言共存"是既成事实，不是设想。
→ **一个语言包可以含多个 xlsx 分册**：日语单册；法语(A1A2 2680 + B1 2902 + B2 2534)
  与俄语(A1A2 2930 + B1 3026 + B2 2495)各三册，**指纹是对并集去重后算的**，
  已复算验证与注册表声明逐字节一致。

**新发现（真问题）**：日语与法语项目的 `BookProfiles.cs` 都**缺俄语条目**
（sha256 都是 `a7f3dd58`，只有 ja/fr 两条），俄语项目的是 `767adff6`（三条齐全）。
→ 每加一种语言，其它语言项目的 3 个 DLL 都得重编译。这是 fork 架构的结构性代价。

**本次交付（全部可复算，未部署、对现状零影响）**：
