# WCP《万词破-单词女友》德语词书项目

复用 `D:\Japanese` (日语词书) / `D:\French` (法语词书) / `D:\Russian` (俄语词书) 的全部管线逻辑与架构契约，为 Steam 游戏《万词破 - 单词女友》(WCP-WordGirlfriend, appid 1981560) 生成 **CEFR 分级德语词书 + 每词 3 条例句 + 单词/例句全套德语发音**。

## 交付总览

**合并单册形态**: 全部词写进游戏**自定义词书四**，书名昵称「德语词库(猫条版)」；槽位一(日语)、二(法语)、三(俄语) 原样保留，互不干扰。

| 分册 | 词数 | 说明 |
|------|------|------|
| A1 | 658 | 基础核心词汇 |
| A2 | 2,830 | 进阶实用词汇 |
| **合计** | **3,488** | 每词 3 条地道德语例句 (共 10,464 条例句) |

- **书名昵称**: `自定义词书四（德语词库(猫条版)）` (SaveFile.es3 `SelfBookName4`)
- **四语共存**: 
  - 槽位一: 日语词库(猫条版) - 7,922 词
  - 槽位二: 法语词库(猫条版) - 8,116 词
  - 槽位三: 俄语词库(猫条版) - 8,451 词
  - 槽位四: 德语词库(猫条版) - 3,488 词
- **全量校验**: `python tools/verify_all_de.py` = **ALL PASS**

## 核心实现与架构对齐

1. **词书与释义**:
   - 词条格式: `[IPA音标] 中文释义〈词性〉`
   - 注入 `MyBook.es3` 的 `SelfBookList4` 与 `SelfBookMeaningDic4`。
2. **共享词库与同形词隔离**:
   - 德语独有词 (3,389 词) 全量注入本地 `wcpFullEng.db` (pron + sentence2) 与 `wcpOnlyWord.db`。
   - 英德同形词 (99 词) 在共享库保持英语原版，由 `DeWordListMod` 运行时在选书切到德语时动态置换，离开时切回英文。
3. **运行时插件支持**:
   - `BookProfiles.cs`: 统一跨语言指纹识别，支持多语言四语注册表。
   - `BookNameMod.dll`: 选书按钮回读保护，外观书名映射，发音按钮支持 DE 标签。
   - `SentenceAudioDeMod.dll`: 每日学习与词典界面的德语例句旁挂绿色 ▶ 播放按钮，支持本地离线播放。
   - `DeWordListMod.dll`: 词书严格隔离 (DeWL_*)、快速/已学词测试题干修复、离线自愈 (`de_db_payload`)。
4. **离线自愈**:
   - 导出 `de_db_payload` (含 TSV 与 SHA-256 manifest)，即使官方更新冲掉 StreamingAssets 数据库，插件启动时也能自动重灌修复。
