## 二、语言学与教学数据规格

### 1. 全要素元数据规范
严格按照《万词破》游戏和专业语言学规范，每个词条配备：
- **`word` (标音词形)**: 现代标准阿拉伯语全动符标音（حركات / Tashkeel），标明开口符、齐齿符、合口符、静符与叠音符。
- **`unvocalized` (检索规范形)**: 去除 Tashkeel 后的规范阿拉伯文字符，供快速模糊匹配与打字查询。
- **`transliteration` (拉丁拼读转写)**: 遵循国际通行的 **ALA-LC** 阿拉伯语标准转写规范（如 `kitāb`, `iqtiṣād`, `dhakā’ iṣṭinā‘iyy`）。
- **`pos` (语法词性)**: 严格标注 `名`、`动`、`形`、`副`、`介`、`代`、`连`、`数` 等。
- **`meaning` (WCP 显示格式)**: 统一为 `[拉丁音标] 中文释义〈词性〉`。
- **`example_ar` & `example_zh`**: 标准阿拉伯语正规例句与精准中文对照。

### 2. 核心手工校准与真实语料对齐
- **语料来源**: 结合 OpenSubtitles `ar_50k`（5 万真实语料词频）、FreeDict `ara_eng`（5.3 万词词典）与 ECDICT（36 万英汉词表）。
- **人工核心映射**: 前 100 高频词与核心虚词（如 `أن`, `كان`, `هو`, `في`, `على`, `لم`, `قد`, `كل`, `مع`）全部通过人工校准表强制修正，彻底杜绝外来人名同形词混淆。

## 三、游戏内导入与使用说明

### 通道一：Excel 零表头导入（推荐各级别分册导入）
《万词破》底层使用 NPOI 解析 Excel（逆向自 `SaveSourceType.LoadDataAndSaveFromExcel`）：
1. 游戏直接读取工作簿的第一个 Sheet，**从第 0 行开始逐行读取**。
2. **A 列 = 单词，B 列 = 游戏显示释义**，C 列及以后被游戏忽略。
3. **不可添加表头行**。本项目 `output/import/*.xlsx` 均为无表头标准格式：
   - A 列：带标音阿拉伯语词头（如 `كِتَابٌ`）
   - B 列：`[kitāb] 书，书籍〈名〉`
   - C-G 列：拉丁转写、词根、例句、译文与分类

**操作步骤**：
- 打开游戏，进入【自建词书】/【词书管理】。
- 点击【Excel导入】，选择 `output/import/` 下对应的 `.xlsx` 词书文件（如先导入专四核心，再导入专八高阶）。

### 通道二：SQLite 外接数据库通道
游戏支持在 `persistentDataPath`（即 `%USERPROFILE%\AppData\LocalLow\WCP\wcp\`）读取外接 SQLite 数据库：
1. 将 `output/import/wcp_arabic.db` 复制到 `%USERPROFILE%\AppData\LocalLow\WCP\wcp\wcp_arabic.db`。
2. 游戏内输入文件名 `wcp_arabic.db`，表名输入 `pron`，词列输入 `word`，释义列输入 `meaning` 即可直接载入。
3. 扩展表 `arabic_all` 包含全量 8,223 条完整例句与词性明细。

### 通道三：多语言四语共存架构
根据全局 `ARCHITECTURE-UNIFIED.md` 规范：
- 槽位一：日语词库(猫条版) - 7,922 词
- 槽位二：法语词库(猫条版) - 8,116 词
- 槽位三：俄语词库(猫条版) - 8,451 词
- 槽位四：德语词库(猫条版) - 8,062 词 / **阿拉伯语考级词库(猫条版) - 8,118 词**
通过 `阿拉伯语考级词库(猫条版).profile.json` 保持唯一的 SHA-256 词集指纹，确保在选书切换时不发生词形污染。
